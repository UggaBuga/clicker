# Кликер

Автокликер / клавишенажималка для Windows с GUI на Tkinter. Две независимые
вкладки — «Мышь» и «Клавиши» — с собственными движками, горячими клавишами,
счётчиками и списками фоновых окон.

**Это нишевый и сыроватый инструмент «для своих»**, а не полированный продукт
для массового пользователя. Он родился из конкретной задачи — фоновой
автоматизации в оконном приложении, которое читает физическую мышь, — и делает
ровно то, что нужно для таких задач, без претензии на универсальность.
Если ты понимаешь, зачем тебе кликер, который тыкает в неактивное окно и
перемещает курсор «в никуда» — скорее всего, он твой. Если нужна «просто
программа, которая кликает» — возьми что-нибудь попроще.

Известные ограничения: интерфейс без претензий, фоновый режим зависит от
чужого окна (что сработает в Wurm Online, может не сработать в другой игре),
телепорт курсора виден, если в этот момент водишь мышью.

## Возможности

- **Два независимых движка** — мышь и клавиатура работают одновременно,
  старт/стоп каждого на свою горячую клавишу (по умолчанию `Insert` и `Home`).
- **Настраиваемый тайминг** — интервал между действиями и случайный разброс
  (± jitter), чтобы действия не выглядели машинными.
- **Случайный сдвиг точки клика** — ±N пикселей по обеим осям.
- **Фоновый режим** — клики и нажатия в неактивное окно: сидишь в браузере,
  кликер работает в игре. Окно при этом не активируется.
- **Телепорт курсора** — для окон, которые читают физическую позицию мыши
  через `GetCursorPos` (GLFW/LWJGL и подобные): перед действием курсор
  перемещается к точке и возвращается на место. Проверено на Wurm Online.
- **Захват точки мыши** с обратным отсчётом и звуковым сигналом — важно для
  фоновых клавиш: игра видит курсор там, куда его «поставил» кликер.
- **Запись горячих клавиш и комбинаций** одним нажатием.
- **Профили** — все настройки активности (тайминги, окно, точки, клавиши)
  сохраняются и подгружаются одним выбором.
- **Аварийный стоп** — мышь в левый верхний угол экрана останавливает движки.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Insert` | старт/стоп движка мыши |
| `Home` | старт/стоп движка клавиш |

Каждая из них переназначается кнопкой «◉». Есть режим «удержание»:
пока клавиша зажата — движок работает, отпустил — остановился.

## Как это работает

- **Активный режим** — реальный ввод через `pyautogui` / `keybd_event`.
- **Фоновый режим** — сообщения окну (`PostMessage`): `WM_MOUSEMOVE`,
  `WM_*BUTTONDOWN/UP`, `WM_KEYDOWN/UP`. Окно не получает фокус.
- **Горячие клавиши** — собственный низкоуровневый хук `WH_KEYBOARD_LL`
  на выделенном потоке (без сторонних библиотек), события маршалятся
  в GUI через очередь; инъектированные нажатия игнорируются, чтобы кликер
  не дёргал сам себя.
- **Телепорт курсора** — `SetCursorPos` к точке действия и обратно: без этого
  игры на GLFW читают позицию мыши напрямую и клик уходит под физический
  курсор, что бы он ни постил в окно.

## Сборка

```bash
pip install pyautogui pywin32 pyinstaller
python -m PyInstaller --onefile --console --name Clicker clicker.py
```

Готовый `Clicker.exe` появится в `dist/`.

## Тесты

```bash
python test_logic.py      # логика: движки, хоткеи, профили
python test_features.py   # режимы, удержание, телепорт курсора
python test_keypos.py     # позиция мыши для фоновых клавиш
python test_e2e_hook.py   # хук + инъекция end-to-end
python test_notepad.py    # фоновый клик в Блокноте
```

## Предупреждение

Использование автоматизации может нарушать правила игр и сервисов.
Используй на свой риск — инструмент предназначен для легитимных сценариев
(тестирование, доступность, собственные приложения).
